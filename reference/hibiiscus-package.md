# hibiiscus: Modelling framework for hierachical ecological impact analysis

This package uses principles of hierarchical modelling to assess the
impacts of land use and land-use intensity on ecological communities.
Data and modelling approach originate from the PREDICTS framework and
are adapted for use with alternative land-use categories (legends),
integration of additional ecological data, modelling with frequentist
and Bayesian approaches, and extended model evaluation.
